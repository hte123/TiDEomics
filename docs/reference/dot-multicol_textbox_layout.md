# Build reusable multi-column textbox grobs and dimensions

Build reusable multi-column textbox grobs and dimensions

## Usage

``` r
.multicol_textbox_layout(text, textbox_args = list())
```

## Arguments

- text:

  A named list of per-module category data.frames.

- textbox_args:

  Arguments passed to the textbox grob helpers.

## Value

A list containing per-module grobs and measured dimensions.
