# `run_WGCNA()` output object for runnable examples

Code for producing the data is available in
[`run_WGCNA()`](https://hte123.github.io/TiDEomics/reference/run_WGCNA.md)
examples

## Usage

``` r
data(example_net)
```

## Format

A list including WGCNA module assignments, module eigengenes,
dendrogram, input data, sample information, and parameters used
