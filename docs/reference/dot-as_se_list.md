# Convert input to a named list of SummarizedExperiment objects

Convert input to a named list of SummarizedExperiment objects

## Usage

``` r
.as_se_list(x, arg = "se_obj")
```

## Arguments

- x:

  Object to convert: a SummarizedExperiment or a named list of
  SummarizedExperiment objects.

- arg:

  Name of the argument (for error message).
