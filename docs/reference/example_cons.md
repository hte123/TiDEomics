# `run_consensus_WGCNA()` output object for runnable examples

Consensus WGCNA of Exp1 (`example_obj`, real) and Exp2 (`example_obj_2`,
simulated), run on the 95 features shared by both datasets.

## Usage

``` r
data(example_cons)
```

## Format

A list with elements: `network`, `multiExpr`, `common_features`, `names`
and `parameters`

## Source

GSE263759

## Details
