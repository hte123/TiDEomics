# Check that an SE list has calc_feature_property results

Check that an SE list has calc_feature_property results

## Usage

``` r
.check_se_list_has_properties(se_obj_list, arg = "se_obj_list")
```

## Arguments

- se_obj_list:

  A list of SummarizedExperiment objects.

- arg:

  Name of the argument (for error message).
